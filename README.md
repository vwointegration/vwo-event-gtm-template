# VWO Event – GTM Template

The **VWO Event** template is a custom Google Tag Manager tag that enables you to send events and event properties from GTM to VWO without writing any JavaScript simply import the template, configure your event name and properties, and the event will stream directly to VWO.

**Features:**
- Send any GTM event and its properties to VWO  
- Add multiple custom properties per event  
- Option to send events for Feature Experimentation using Offline Conversions  

## Requirements

- Google Tag Manager container (Web)
- VWO account
- For SmartCode mode: VWO SmartCode installed on your website
- For Direct POST mode: VWO Account ID and access to visitor ID
